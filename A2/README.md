HCDE 410 A2 — Exploring Sources of Bias in Data
This notebook investigates the Wikipedia Talk Corpus, focusing on the demographics of crowdworkers who labeled Wikipedia comments and on possible biases in toxicity annotations. The questions follow the course A2 assignment, including Q1–Q8 and the Q13–Q16 qualitative option.
Original data and terms
- Original source: Wikimedia Research:Detox/Data Release, Wikipedia Talk Labels: Toxicity (Figshare).
- Source data license: CC0 public-domain dedication (Wikimedia). Cite the original dataset when reusing it.
- The included LICENSE file is the course/project's MIT license, separate from the underlying dataset license.
- The TSVs and 3,000-row CSV were provided as course materials; the analyses here were prepared on 2026-10-25, not by downloading fresh source data directly.
Input files
- toxicity_worker_demographics.tsv: 3,591 records.
- attack_worker_demographics.tsv: 2,190 records.
- aggression_worker_demographics.tsv: 2,190 records; identical to attack demographics, so excluded from the corrected pooled counts.

The notebook supports these files either alongside it or under a wikipedia_datasets/ subfolder.

Research questions and findings
- Q1–Q4: Gender, English first language, age, education distributions for 5,781 dataset-specific survey records.
- Q5: Missing data: 112 records (1.94%) have missing age group; no other supplied field is missing.
- Q6: Including both identical attack and aggression files produces a misleading 7,971 records and changes demographic percentages.
- Q7–Q8: Assess representativeness and problems in generalizing Wikipedia toxicity labels to other platforms.
- Q13–Q16: Review disagreement, unclear context, the questionnaire, and possible model consequences.
Limitations and possible sources of bias
The demographic files describe optional survey respondents, not everyone who annotated the corpus. Matching worker_ids across separate datasets do not establish shared real-world identities, so 5,781 should be read as dataset-specific demographic records. Duplicate files can change the weighting of groups: for example, the male share is 63.59% in corrected data and 63.04% when the attack/aggression file is double counted. More broadly, individual toxicity ratings may depend on cultural expectations, conversational context, and the instructions' mixing of hostility with constructiveness. These are plausible sources of bias; this notebook does not establish model-level error rates.

The qualitative review sheet contains a targeted 60-record review, not a representative random evaluation of accuracy. Some comments include offensive text.
